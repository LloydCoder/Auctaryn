# Support

- **Usage questions and documentation gaps:** open a GitHub Issue after searching existing issues and docs.
- **Reproducible defects:** use the bug-report template and include the affected commit, environment, steps, expected/actual behavior, and sanitized logs.
- **Feature ideas:** use the feature-request template and describe the user problem and acceptance criteria.
- **Security vulnerabilities:** do not use public issues; follow [SECURITY.md](SECURITY.md).
- **Contributor conduct concerns:** contact hello@tinlance.com as described in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Remove credentials, tokens, private keys, customer identifiers, personal data, and sensitive infrastructure details before sharing logs.

Auctaryn is maintained under a single-maintainer model. Support is best-effort and is not a commercial SLA. Response times and fixes are not guaranteed. A local demo or green CI run does not establish production readiness or a verified external runtime integration.
