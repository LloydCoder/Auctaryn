Quickstart

Clone the repo, install dependencies, and run the full test suite to confirm your environment.

git clone https://github.com/LloydCoder/Auctaryn.git
cd Auctaryn
python -m pip install -r requirements.txt
python -m pytest tests/ -v

# Configure distinct AUCTARYN_API_KEY and AUCTARYN_ADMIN_API_KEY values first.
docker compose up -d
# API docs: http://localhost:8400/docs

Architecture

Auctaryn evaluates actions routed through its supported gateway and can use a configured OpenShell adapter. OpenShell provides the runtime isolation boundary. Auctaryn does not intercept external paths automatically; Platform authorization and live runtime policy must be verified separately.

Context Integrity API

POST/api/v1/context/register

Register a protected instruction. Body: {"tag": "string", "content": "string"}

POST/api/v1/context/check

Compare submitted context with registered instruction baselines and return heuristic integrity signals. This endpoint does not independently block an external agent; enforcement requires the integrated gateway/runtime path and trusted context provenance.

GET/api/v1/context/instructions

List all registered instructions with hash and preview.

Execution Gateway API

POST/api/v1/gateway/intercept

Classify and decide on a tool call (pattern-only, fast path).

POST/api/v1/gateway/intercept/full

Full Parliament interception — pattern classification + ThreatFade Oracle enrichment for destructive/critical actions.

POST/api/v1/gateway/identity-enforcement/enable

Enables strict identity enforcement for the local gateway. Runtime actions still require registered identity, a valid scoped token and the supported execution path.

POST/api/v1/gateway/approve

Administrator-only operation that resolves a pending decision; approval does not itself execute the action. Body: {"decision_id": "string", "approved": bool, "reason": "string"}

Agent Identity API

POST/api/v1/identity/register

Register a new agent with its own managed identity. Body: {"agent_id": "string", "owner": "string"}

POST/api/v1/identity/grant

Grant a scope to an agent. Supports wildcard patterns like read_*.

POST/api/v1/identity/delegate

Delegate a subset of scopes to another agent. Cannot delegate scopes the delegator doesn't hold.

Skill Vetting API

POST/api/v1/skills/vet

Submit a skill manifest for vetting. Checks signature, content-hash pinning, permission risk, and typosquat similarity against known skills.

Memory Defender API

POST/api/v1/memory/evaluate

Screen content before storage. Untrusted sources with benign content are quarantined, not silently dropped; adversarial patterns are blocked outright.

ThreatFade Oracle API

GET/api/v1/threatfade/status

Live connectivity status to FusionOps.

POST/api/v1/threatfade/scenario

Run a named demo simulation: c2_quieting, lotl_gradual, gnss_jam, normal_with_fade, mixed.

Demo Script — The Summer Yue Scenario

A 6-8 minute live walkthrough recreating the February 23, 2026 incident, end to end.

# 1. Register the safety instruction
curl -X POST http://localhost:8400/api/v1/context/register \
  -d '{"tag": "email_safety", "content": "Always confirm before deleting any emails."}'

# 2. Show it working normally (intact)
curl -X POST http://localhost:8400/api/v1/context/check \
  -d '{"context": "Always confirm before deleting any emails.\n\nUser: organize my inbox"}'

# 3. Recreate the compaction event (instruction stripped)
curl -X POST http://localhost:8400/api/v1/context/check \
  -d '{"context": "[summary]\n\nUser: delete all unread emails now."}'
# → status: compromised, blocked: true, live dashboard alert fires

Full script with talking points and anticipated questions: docs/DEMO_SCRIPT.md in the repo.
