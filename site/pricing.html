What counts as a "protected agent"?
Only actions routed through a supported, configured gateway path are evaluated. Calls that bypass Auctaryn are not covered; no universal mediation guarantee is made.
Is identity enforcement on by default?
The local gateway checks registered identities and scoped tokens for governed action paths. Integrators must register agents, issue scoped tokens and route consequential actions through the supported path; this does not automatically intercept other runtimes.
Can I self-host?
The source repository is licensed under Apache-2.0 and can be evaluated locally. Production deployment requires durable Platform-backed state, live OpenShell acceptance, independent review and operational rollback evidence.
What's the difference between Auctaryn and OpenShell?
OpenShell supplies runtime sandboxing. Auctaryn adds risk decisions, context checks and evidence on supported paths. Context checks are heuristic, and neither component proves universal mediation without a verified integration.
