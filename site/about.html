About

Built by Tinlance Limited

An AI and cybersecurity engineering studio. TwinGuard is one piece of a connected ecosystem of security products — all wired through a shared threat intelligence hub.

Why we built this

A real incident, not a hypothetical.

On February 23, 2026, an autonomous AI agent deleted a user's entire email inbox after a context compaction event silently stripped its safety instructions. That single incident is the reason TwinGuard exists. NVIDIA OpenShell sandboxes what an agent can touch. Nothing was protecting what an agent reasons over and decides. We built the layer that was missing.

ThreatFade — the foundation
A C2 detection engine validated against real Merlin QUIC malware (z-score 14.76, 490K+ packets), Cobalt Strike, and IcedID. Open-source, built from five merged PRs across major security tools.
FusionOps — the threat hub
A live SOC platform wrapping ThreatFade in a full detection/triage/remediation pipeline. Every product in the ecosystem routes network threat intelligence through this single hub.
TwinGuard — agent containment
Built on NVIDIA OpenShell, consuming ThreatFade via FusionOps as its ThreatFade Oracle. 232 tests, 10/10 OWASP ASI categories represented in code.
How we work

Test-driven. Honestly scoped.

Tests before code
Every module is built red-green-refactor. Tests are written first, watched to fail, then implemented against.
Honest status, always
We document what's MVP-depth vs. production-hardened. No category is claimed "covered" without working code behind it.
Fail-safe by default
If a dependency like FusionOps is unreachable, TwinGuard degrades gracefully — it never crashes or silently blocks legitimate agents.
Open-core, always
The security-critical core ships Apache 2.0. Enterprise tiers add scale and support, never withhold core protection.
